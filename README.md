# ¿Dónde están mis pantalones?

Página web simple inspirada en la pregunta de la película *Lluvia de hamburguesas*.

Un botón dispara la pregunta y aparecen globos de texto por toda la pantalla con
respuestas posibles y otras completamente descabelladas.

## Uso

Es HTML/CSS/JS puro, sin dependencias ni build. Basta con abrir `index.html`
en un navegador, o servir la carpeta con cualquier servidor estático:

```bash
npx serve .
```
